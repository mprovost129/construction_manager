On the QuickBooks computer

  1. Coordinate with the QuickBooks administrator. Confirm a current backup and the active file’s storage/sync settings. Prefer a separate test copy for the first installation.
  2. Open the intended company in QuickBooks and sign in as its administrator. Press F2 to find the exact company name and file location.
  3. Prepare this page’s setup form. Choose a dedicated Web Connector password and save it privately. It will not be displayed again.
  4. Download the .qwc setup file on that computer. Install a compatible Intuit Web Connector if needed. Use Add an Application in Web Connector to open the downloaded file.
  5. Approve the Heritage 360 application in QuickBooks. Confirm the website matches Heritage 360. Do not grant access to personal data such as Social Security numbers. Keep the intended company open for the check.
  6. Enter the dedicated password in the Heritage 360 row in Web Connector. Select that row and click Update Selected. Leave Auto-Run off.
  7. Return here and choose Refresh status. A successful check shows Company verified. If the check fails, follow the displayed help and request another check before trying again.

Keep one computer responsible for this connection. Other team members use their own Heritage logins; they do not each install another connector. Do not send passwords or company files through chat.
